# Path B Case 003 — 原场景锁定融图 / 场景语言创意重拍

日期：2026-08-25  
案例用途：Path B v0.5 默认双候选结构与用户交互验收  
当前状态：A / B 候选质量与交互定义通过；按 v0.6 候选组确认规则，不要求用户提前选择单张候选

## 本次目标

使用已确认的 NINJA 双篮空气炸锅产品母版和用户上传的暖色石材厨房，输出 1000 × 1000 的两种 Path B 候选：

- Candidate A｜原场景锁定融图：直接把产品放进用户上传的背景。
- Candidate B｜场景语言创意重拍：保留参考场景的材质、色彩、光线和气质，为产品重新设计镜头与陈列。

本案例用于验证 A / B 是否应当代表两种制作逻辑，而不是先选择一种方法后再在该方法内部制造两个构图版本。

## 输入角色与实际像素

- 产品身份来源：`../path-a-001/confirmed/ninja-product-master-confirmed-1200x1200.png`，1200 × 1200 PNG。
- 指定背景原图：`source/warm-stone-kitchen-original.png`，736 × 1104 PNG。
- Candidate A 方形基础画面：`source/warm-stone-kitchen-square-crop-736x736.png`，736 × 736 PNG。
- 目标交付像素：1000 × 1000 PNG。
- 输出工具：内置 image generation；每个候选独立调用。

背景原图为 2:3 竖图，目标为 1:1 方图。Candidate A 先确定性裁切为 736 × 736 的方形基础画面，再进行产品融入；Candidate B 直接从原图提取并重建指定场景身份。

## 用户确认的候选计划

| 对比项 | Candidate A｜原场景锁定融图 | Candidate B｜场景语言创意重拍 |
|---|---|---|
| 核心做法 | 直接把产品放进这张背景 | 保留场景气质，为产品重新组织画面 |
| 背景处理 | 保留原镜头、空间结构、花瓶、吊灯与可见陈列 | 保留暖色石材、黄铜、木质、奶油色橱柜和自然光，允许重组空间 |
| 商品位置与镜头 | 空气炸锅落在岛台右侧，延续原背景视角 | 移除大型花瓶，采用斜俯拍商品英雄构图 |
| 食物与道具 | 不增加食物，不主动重排背景 | 增加两组克制的空气炸锅食物，辅助双篮联想 |
| 画面价值 | 产品真实进入当前照片 | 同一场景语言下的商品广告重拍 |
| 共同边界 | 同一产品母版、1000 × 1000、双篮闭合、产品第一、不加人物或文字 | 相同 |

用户确认计划后授权同时生成 A / B。

## 本案例确认的 v0.5 规则

1. Path B 默认不再先问用户选择“原镜头融图”或“同场景换镜头”。
2. Candidate A 固定代表“原场景锁定融图”，Candidate B 固定代表“场景语言创意重拍”。
3. 固定的是制作逻辑与名称，不是具体构图；商品位置、镜头、食物与道具仍按产品证据和背景条件动态规划。
4. `原场景锁定` 默认锁定场景身份、镜头、空间结构和主要陈列关系，不自动等于背景像素级不变。
5. 用户明确要求像素不变时，必须单独启用可验证的确定性处理，或停止并说明能力边界。
6. Candidate B 可以移除阻碍商品展示的物体、改变镜头和周边关系，但必须保留指定场景身份、保持商品第一且不虚构产品结构。
7. 两张候选分别 QA；一张通过不能掩盖另一张失败。最多一次合理重试，之后由用户提出修改意见或回复“无修改意见”；两张均合格时不要求二选一，只有后续用途需要单张时才选择。

## 结论

本案例证明，按两种制作逻辑组织 Path B 的 A / B，比在单一方法内部通过缩放或镜头微调制造候选更直观，也更有商业决策价值。用户已接受 Candidate A 的非像素级场景锁定口径，并确认继续进入候选组确认规则修正。两张候选分别通过 QA 时，用户可直接回复“无修改意见”，不必选择唯一一张；当前案例作为双候选交互证据收口，不自动进入 Path C。
