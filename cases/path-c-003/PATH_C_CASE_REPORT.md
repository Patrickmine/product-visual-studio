## 失败分类与规则修正

本案例暴露的不是“需要更多装饰”，而是缺少有条件的住宅场景正向标准：当参考图和核心目标要求生活化家庭场景时，应有少量与备餐、操作和清洁区域对应的功能物件，同时保留开放工作面；空样板房和无功能装饰堆砌都不应通过场景合理性 QA。

该规则已窄范围补充至 `references/path-c-reference-visual-rebuild.md`。它不适用于刻意极简、棚拍或非住宅场景，也不改变产品保真、来源距离、A/B 候选或纯图片边界。
